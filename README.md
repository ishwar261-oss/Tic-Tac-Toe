# Tic Tac Toe

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## About

This project is a browser-based Tic Tac Toe game for two players.

Players take turns placing **O** and **X** on a 3×3 game board.

The game automatically detects:
- Winner
- Draw
- Game reset
- New game

## How to Play

1. Player O starts the game.
2. Players take turns clicking an empty box.
3. The first player to complete a row, column, or diagonal wins.
4. If all 9 boxes are filled without a winner, the game ends in a draw.
5. Use **Reset Game** or **New Game** to start again.

## Technologies

- HTML
- CSS
- JavaScript

## Project

A beginner-friendly JavaScript project created to practice DOM manipulation, event listeners, game logic, and conditional statements.
